# Travel & Tourism Web Portal 🌍✈️

A responsive Single Page Application (SPA) designed to provide a seamless travel booking and exploration experience. 

## 🛠️ Tech Stack
* **Frontend:** React.js, JavaScript (ES6+)
* **Styling:** CSS3 (Flexbox & Grid)
* **Tools:** VS Code, Git

## ✨ Key Features
* **Modular Component Architecture:** Built with reusable React components for high scalability and clean code structure.
* **Mobile-First Responsive UI:** Designed utilizing CSS Flexbox and Grid to ensure perfect rendering across all device sizes.
* **Real-Time Input Validation:** Implemented strict client-side validation logic for user inputs (email/phone) to minimize server-side processing load.
* **Optimized Performance:** Engineered with efficient DOM manipulation and asset loading strategies to achieve smooth user experiences and high performance scores.

## 🚀 How to Run Locally
1. Clone the repository: `git clone https://github.com/EklavyaGoyal1757/Travel-Tourism-Web-Portal.git`
2. Navigate into the directory: `cd Travel-Tourism-Web-Portal`
3. Install dependencies: `npm install`
4. Start the development server: `npm start`
